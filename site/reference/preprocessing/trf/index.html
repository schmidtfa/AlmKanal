Stimulus epoching and WAV alignment

StimulusEpochs divides each stimulus trial into non-overlapping, fixed-length epochs and appends one or more WAV-derived stimulus features. The resulting epochs can be used for TRFs and other analyses. Use feature="envelope" for a single feature or feature=["envelope", "mel_onsets"] to append several features. resample_sfreq=200.0 resamples trial segments after alignment and physical-delay correction, before computing features at 200 Hz; None retains the input rate.

StimulusSpanSpec describes the trial spans and audio files used for this workflow.

almkanal.almkanal_steps.stimulus_utils.StimulusEpochs

Bases: AlmKanalStep

Create fixed-length epochs within stimulus trials and attach WAV features.

Optionally correct the recording clock, apply a fixed neural timing shift, then split trials into non-overlapping epochs with WAV features as misc channels. Defaults below describe the general profile; omitted settings use the active profile captured when the step is constructed.

Notes
  • Recorded audio: takes precedence over assumed drift and needs sufficient signal bandwidth. Failed fits follow on_alignment_error without falling back to assumed drift. For long stimuli, increase alignment_kwargs['max_lag_s'] to cover offset plus accumulated drift; see estimate_raw_wav_alignment for search limits and quality warnings.
  • Assumed drift: uses t_raw = (1 + drift / 1e6) * t_wav relative to trial onset. Positive drift lengthens raw time. The WAV determines trial duration; the end trigger does not determine drift. No offset is measured.
  • Physical delay: applied after clock correction, rounded to a sample. WAV features stay unchanged. Use zero if the audio reference already represents sound arrival at the ears. Alignment needs raw coverage for the full WAV plus delay margins; insufficient coverage is an alignment error.
  • Salzburg defaults: hw_delay_s=0.0165 compensates the 16.5 ms air-tube delay when the reference precedes the tubes. The profile also sets audio_channels=('MISC007', 'MISC008') and fallback_drift_us_per_s=499.0. Pass audio_channels=None explicitly to use assumed drift with this profile.

Notes

End inference uses WAV duration * (1 + drift / 1e6) and leaves the trigger channel unchanged. It only defines spans: to also resample neural data without recorded audio, set realign_without_audio=True on :class:EpochStimuls and use the same fallback_drift_us_per_s. Notes

Recorded audio takes precedence over assumed drift, including when a fit fails. Clock correction precedes the sample-rounded hw_delay_s shift; WAV features are not shifted. Alignment requires recording coverage for the full WAV duration plus any physical-delay margins.
