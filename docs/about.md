## About AlmKanal

AlmKanal is developed at the Salzburg Brain Dynamics Lab. It builds on MNE-Python and brings together explicit Python pipelines, user-defined processing steps, supported ordering checks, multimodal alignment, and Methods reporting.

Its pipeline architecture is inspired by scikit-learn's make_pipeline API. Text configuration files remain useful in other workflows; AlmKanal emphasizes direct composition in Python.
